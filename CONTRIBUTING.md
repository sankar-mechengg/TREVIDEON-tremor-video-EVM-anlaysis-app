# Contributing to TREVIDEON

Thank you for helping! Bug reports, test videos (with consent), documentation and code are all welcome.

* **Issues**: describe the video (fps, resolution, camera), the settings and what you expected.
* **Code**: fork, create a branch, keep changes focused, and open a pull request. Backend code is Python
  (FastAPI, NumPy, OpenCV, PyTorch); the website is React + Vite.
* **Scientific changes** (anything that changes measured numbers) should bump `PIPELINE_VERSION` in
  `backend/evm/config.py` and explain the method in the pull request.
